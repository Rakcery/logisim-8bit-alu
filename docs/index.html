Numbers as bits

Inside the circuit every wire is either off (0) or on (1). Eight wires side by side hold one 8-bit number. Each position is worth twice the one to its right:

1286432168421
100 =0110010064 + 32 + 4

So 8 bits can hold 0 to 255. The same bits can also be read as a signed number from −128 to 127: if the leftmost bit is 1, the number is negative (11111111 is −1, 10000000 is −128). The circuit does not care which reading you use. The flags tell you what happened under each one.

The clock and the control unit

In the full circuit (main) the ALU sits between registers, small memories that only change when a clock ticks. A control unit with four states decides what each tick does. Try it with the numbers and operation chosen above:

Two flip-flops remember the state as two bits (S1 S0). In LOAD the registers for A and B are told to store; in EXECUTE the output register and the flag register are told to store. This is a Moore machine: what it does depends only on the state it is in.

From the 4-bit course project to 8 bits

This started as the final project of a Digital Logic Design course: a 4-bit ALU with 9 operations. It was later rebuilt as this 8-bit version, with the bugs fixed and every block tested.
